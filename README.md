## 📌 Project Overview

This project was completed as part of my **Level 3 Data Technician Bootcamp with Leep Talent**.

I used **Tableau** to explore, analyse and visualise retail and sales datasets, transforming raw business data into interactive dashboards and meaningful insights.

The project focused on developing practical data visualisation, analytical thinking and data storytelling skills to support business decision-making.

---

## 🎯 Project Objectives

- 📊 Build interactive dashboards to monitor sales performance.
- 🔍 Explore retail data using filters and interactive controls.
- 📈 Identify sales trends and customer purchasing patterns.
- 🧮 Create calculated fields for business metrics.
- 🌍 Compare sales performance across geographical regions.
- 💡 Communicate insights through effective data storytelling.

### 🧮 Calculated Fields

Used Tableau calculated fields to create business metrics and support analysis.

| Technique | Application |
|-----------|-------------|
| `SUM()` | Calculate total sales |
| `AVG()` | Calculate average sales |
| `COUNT()` | Count transactions |
| `IF / THEN` | Create conditional calculations |
| `DATEPART()` | Extract date components |
| Calculated Fields | Develop custom KPIs |

## 💡 Data Storytelling

A key part of this project was learning how to communicate findings through visualisations.

Rather than simply displaying charts, I focused on creating dashboards that help users:

1. **Understand** overall sales performance.
2. **Explore** trends through interactive filters.
3. **Compare** product categories and regions.
4. **Identify** patterns and potential opportunities.
5. **Make decisions** using clear visual evidence.

The project strengthened my ability to turn complex datasets into accessible and meaningful business information.
